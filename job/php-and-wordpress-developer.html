Job Description

We are seeking a highly skilled .NET Core Full Stack Developer to join our team at CloudConverge. You will be responsible for developing and maintaining software applications using .NET Core, C# and related technologies.

Responsibilities

  • Design, develop and deploy high-quality software solutions using .NET Core, C# and ASP.NET.
  • Collaborate with cross-functional teams to gather requirements, define, develop and deploy new features and enhancements.
  • Participate in all phases of the software development life cycle, from requirements gathering to deployment and maintenance.
  • Write clean, efficient code and well-documented code adhering to best practices.
  • Troubleshoot and debug software defects for optimal performance.

Qualifications

  • Strong experience in developing web applications using .NET Core, C# and ASP.NET.
  • Proficient in front-end technologies such as HTML5, CSS3, JavaScript, and modern frameworks (e.g., Angular, React, or Vue.js).
  • Solid understanding of relational database systems and SQL (e.g., SQL Server, MySQL, or PostgreSQL).
  • Experience with version control systems (e.g., Git) and agile development methodologies.
  • Familiarity with cloud platforms (e.g., AWS, Azure) and containerization technologies (e.g., Docker) is a plus.
  • Strong problem-solving skills and attention to detail.
  • Excellent communication skills and collaborative abilities.
