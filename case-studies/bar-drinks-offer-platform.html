Bar & Drinks Offer Platform - ToddyOffers

Client was looking to create to a Marketplace Portal and App for customers looking to Search, View, Book / Purchase offers provided by various Bars & Pubs across India. The solution offers capability for Bar owners to manage their inventory, manage offers, view, approve bookings, validate user entry. The solution has its own virtual currency, users an deposit funds, purchase offers from the app.

The solution has a number of features for users to invite their friends for a get together, other users will be able to add their own drinks from the app. The users can decide to pay for themselves or can have the organizer pay for them. The solution was developed using .NET Core (for Web Portal) and Flutter (for Mobile Apps) with Microsoft Azure.

User Experience Design & Backend Integration

Since the solution was to act as a marketplace, with Bars, Pubs managing their Catalog, Managing Orders and Bookings, Users being able to browse through a large Catalog, Make bookings and purchases, designing an intuitive interface was the core principal which drove the design exercise for this project. The solution was developed using .NET Core with Angular, using Microsoft Azure Services.

Conclusion & Feedback

The solution was launched with a lot of fanfare, press coverage and celebrity endorsement. The application had over Ten Thousand downloads within the first One week of launch. We are happy to be part of ToddyOffers.com journey from conceptualizing to public launch of the solution.
